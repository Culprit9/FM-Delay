# Factory presets — FM DELAY 0.11.0

37 programs. Every factory preset loads in note Sync and follows the host tempo. Short free-time recipes now use the closest note subdivision at 120 BPM: Velvet/Backbeat/Hype Slap use dotted 32nds; Pocket Double uses sixteenth-triplets; Nashville Slap uses sixteenths; Felt Room and Radio Delay use eighth-triplets. Select a category/name in the top browser; arrows audition neighbors. Reload restores the selected factory recipe after edits. Edited means your settings differ; DAW state saves those changes.

The instrument and adlib recipes are moderate insert starting points. For an aux/send return, use Mix 100%. Throw recipes require a click to start capture and another click to stop; echoes continue afterward.

**FM's Fav Delay now matches Donnie’s October 29 screenshot approximately**, superseding the earlier literal-max recipe: half-note Sync, Feedback 68%, Mix 70%, Analog 50%, Ducking off, HP 370 Hz, LP 9500 Hz, Width 1.00, Diffusion 100, Dark, Ping on, Throw off, Threshold -39.385 dBFS. At 105 BPM the half note is 1142.9 ms; it follows host tempo. Hidden knob numbers were estimated with Donnie’s approval; visible switches, note and threshold were copied. Existing edited instances retain their values until Reload.
